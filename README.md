# 📊 Power BI Project: Interactive Mobile Sales Analytics Dashboard
This project presents an end-to-end interactive Power BI dashboard designed to analyze mobile sales performance across multiple dimensions such as brand, city, time (month/day), mobile model, payment method, and customer ratings. The dashboard enables users to explore key business KPIs including Total Sales, Total Orders, Total Quantity, and Average Price, with dynamic slicers and filters for deep-dive analysis. It helps transform raw transactional data into clear, actionable insights for data-driven decision-making.

## What this project can do:
- Track overall sales performance using business KPIs
- Analyze sales trends by month and day
- Compare performance across brands, cities, and mobile models
- valuate payment method distribution and customer ratings
- Interactively filter and explore insights using slicers

## Skills & Topics Covered:
- Power BI (Dashboard design & data visualization)
- Power Query (ETL, data cleaning & transformation)
- Data Modeling (relationships, star schema concepts)
- DAX (measures for KPIs and business metrics)
- Calculated Columns
- KPI design, interactive slicers, and report optimization

## Project Outcome
Developed a fully interactive Power BI sales dashboard that converts raw transactional data into clear, actionable business insights. The solution enables stakeholders to quickly monitor key KPIs (Total Sales, Orders, Quantity, Average Price), identify top-performing brands and cities, track monthly and day-wise sales trends, and understand customer behavior through payment methods and ratings. The project demonstrates the ability to design business-ready dashboards, implement accurate data models and DAX measures, and deliver insights that support data-driven decision-making.
